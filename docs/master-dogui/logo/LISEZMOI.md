# Pack logo MASTER DOGUI

Vectorisé à partir du logo noir et blanc fourni (tracé fidèle, courbes propres, aucun pixel). Le fichier couleur d'origine (disque flou) n'est plus utilisé : les versions couleur sont reconstruites en vectoriel.

| Fichier | Usage |
| --- | --- |
| `master-dogui-symbole-noir.svg` | Impression monochrome, tampons, documents sur fond clair |
| `master-dogui-symbole-blanc.svg` | Sur fond sombre ou photo foncée |
| `master-dogui-symbole-or.svg` | Dégradé or, fond transparent |
| `master-dogui-icone-disque.svg` | Pastille ronde (profils, réseaux sociaux) |
| `master-dogui-icone-app-arrondie.svg` | Icône d'application (coins arrondis) |
| `master-dogui-icone-maskable.svg` | Icône adaptative Android / PWA (symbole dans la zone de sécurité) |
| `master-dogui-icone-petite-taille.svg` | Favicon et icônes 16 à 64 px (version simplifiée) |
| `master-dogui-horizontal-fond-clair.svg` / `-fond-sombre.svg` | En-têtes, rapports PDF, présentation (texte converti en tracés) |
| `png/` | Exports matriciels (512, 1024 ; petite taille 32, 48, 64, 180, 192, 512 ; horizontaux 1400) |

## Couleurs
Or : #FFE07A, #F6B92B, #E88409 (dégradé vertical) · Bleu nuit : #0B2A8A vers #020A2C · Halo : #2F6BFF · Texte clair : #0A1F6B (DOGUI #D97A06) · Texte sombre : #FFFFFF (DOGUI #FFD25A).

## Règles
Zone de protection : largeur d'un nœud du circuit. Taille minimale du symbole détaillé : 48 px (en dessous, icône simplifiée). Sur fond chargé : noir ou blanc. Interdit : déformer, pivoter, recolorer, ajouter ombre ou halo, agrandir un PNG.

## À faire par un graphiste (facultatif)
Le texte « MASTER DOGUI » utilise la police Liberation Sans Bold convertie en tracés. Une typographie définitive peut être choisie ; l'icône simplifiée est un dessin fonctionnel à valider visuellement.
